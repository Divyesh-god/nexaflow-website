# NexaFlow SaaS Website

A responsive, polished front-end website concept for a fictional SaaS project-management company. Built with plain HTML, CSS, and JavaScript—no build tools or paid services required.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive design and visual styling
- `script.js` — mobile menu, pricing billing toggle, and demo sign-up form

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a browser. For best results, use a local server or publish the folder as a static website.
3. Edit the brand, copy, prices, and contact details to match your actual client brief.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account and make a new public repository.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub to provide the published URL.

You can also deploy the folder using Netlify Drop or another static hosting provider.

- NexaFlow is a fictional brand created for this sample project. Replace it if the client supplied a brand name or logo.
- The email sign-up form is front-end only; it does not send or store submissions. Connect a backend or form service before using it for real customers.
- Pricing is illustrative and must be confirmed before a real commercial launch.
